# Logo sources

`logo.svg`, `app_icon.svg` and `splash.svg` are the editable versions of the
PNGs one folder up. The text uses the **Lilita One** font
(`game/art/fonts/LilitaOne-Regular.ttf`), so install it before opening them in
an editor such as Inkscape or Figma. The wolf, lion and claw marks are icons
by Lorc from game-icons.net (CC BY 3.0).

The `.gdignore` file keeps Godot from importing these sources.
